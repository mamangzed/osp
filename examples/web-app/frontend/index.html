🛒 Real-time Shop

Connecting to OSP...
💡 How it works: This demo shows real-time sync using OSP. When you create an order:
1. Frontend calls PHP API (HTTP POST) for business logic
2. PHP validates, saves to database, updates OSP
3. OSP broadcasts updates to ALL connected clients (WebSocket)
4. All browsers see updates in real-time!

Try it: Open this page in 2 browser windows and create an order!
